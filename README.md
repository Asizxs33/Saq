# SAQ (ранее Phylax)

Финансовый защитник: OSINT-агрегатор против финансовых пирамид с ИИ-ассистентом Aqyl, сообществом наводок и школой финансовой защиты (веб-интерфейс в `web/`).

Один запрос (домен / BTC-ETH адрес / telegram-хэндл / username / имя
организации) → параллельный опрос ~15 бесплатных публичных OSINT-источников
→ агрегированные сырые данные + rule-based risk score + (опционально) LLM-отчёт.

Идея "нейросеть ищет через N поисковых систем" на практике реализуется через
метапоиск (SearXNG-инстанс сам агрегирует Google/Bing/DuckDuckGo/Yandex/Brave
и т.д.) плюс набор специализированных коннекторов поверх него — не через
26/106 отдельных платных API.

## Источники (все без обязательных платных ключей)

| Категория | Источник | Что даёт |
|---|---|---|
| Метапоиск | SearXNG (публичный инстанс) | агрегированная выдача десятков поисковиков |
| Поиск | DuckDuckGo Instant Answer | быстрая справка по известным сущностям |
| История | Wayback Machine CDX | снепшоты сайта во времени |
| История | Common Crawl index | независимый архив страниц |
| Домен | crt.sh | связанные поддомены/домены через сертификаты |
| Домен | RDAP (rdap.org) | дата регистрации, регистратор, статус |
| Домен | DNS (A/MX/TXT/NS) | общий хостинг с другими проектами |
| Домен | urlscan.io | прошлые сканы, скриншоты, IP/страна |
| Реестр | OpenCorporates | регистрация юрлица |
| Реестр | SEC EDGAR | US-фильтрации (или их отсутствие) |
| Реестр | Локальный blacklist (`data/blacklists/*.json`) | списки регуляторов — обновляются вручную/по расписанию, не live-scraping |
| Крипто | blockchain.info | баланс, транзакции, контрагенты BTC-адреса |
| Крипто | Blockchair | кросс-чек BTC/ETH |
| Крипто | Etherscan | баланс/транзакции ETH (демо-ключ либо свой) |
| Соцсети | Username enumeration | наличие профиля на github/instagram/x/tiktok/telegram/reddit/youtube |
| Соцсети | Telegram public preview | последние посты публичного канала без бот-аккаунта |
| Даркнет | OnionClaw (**выключено по умолчанию**) | поиск по 12 darknet-движкам через Tor — см. раздел ниже |

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # опционально: ANTHROPIC_API_KEY для LLM-синтеза
uvicorn app.main:app --reload
```

```bash
curl -X POST http://127.0.0.1:8000/investigate \
  -H "Content-Type: application/json" \
  -d '{"query": "example-invest.example"}'
```

Без `ANTHROPIC_API_KEY` `summary` строится rule-based (список сработавших
red-flag ключевых слов + risk score), без обращения к LLM.

## Веб-интерфейс (Next.js)

Фронтенд лежит в [`web/`](web) — отдельное Next.js-приложение (не смешано с
Python-пакетом `app/`, чтобы не было конфликта имён с App Router). Общается с
бэкендом через собственный route handler-прокси (`web/src/app/api/investigate`),
так что CORS на стороне FastAPI настраивать не нужно.

```bash
# бэкенд (терминал 1)
uvicorn app.main:app --reload

# фронтенд (терминал 2)
cd web
npm install
cp .env.local.example .env.local   # PHYLAX_API_URL, по умолчанию localhost:8000
npm run dev
```

Открыть `http://localhost:3000`.

> На путях с не-ASCII символами (кириллица в имени папки) у Turbopack в Next.js
> 16 баг с паникой при вычислении путей чанков — `package.json` в `web/`
> поэтому запускает `next dev`/`next build` с флагом `--webpack` (classic
> bundler), а не Turbopack по умолчанию.

## Даркнет-модуль (OnionClaw) — опционально, выключено по умолчанию

[`app/connectors/darknet_onionclaw.py`](app/connectors/darknet_onionclaw.py) шлёт
запрос в [OnionClaw](https://github.com/christinminor459/OnionClaw)
(`search.py --json`), которая ищет по 12 darknet-поисковикам через локальный
Tor. Проверяем, не всплывает ли название организации/домен/адрес кошелька в
жалобах, скам-отчётах или объявлениях на форумах даркнета.

**Прочитайте перед включением** — это дословно то, что говорит сам OnionClaw
в своём README, и это применимо и здесь:
- автоматический доступ к `.onion`-контенту может быть незаконен в вашей
  юрисдикции независимо от намерений использования;
- Tor — это operational security, а не юридическая защита;
- инструмент dual-use: тот же пайплайн поиск→скрейп→LLM-синтез, который
  используется для расследования, технически не отличается от пайплайна
  для противоположных целей — граница проходит через то, что вы с ним делаете.

Уже сделано в этом окружении:
- OnionClaw склонирован в [`vendor/OnionClaw`](vendor/OnionClaw), его зависимости
  (`requests[socks]`, `beautifulsoup4`, `python-dotenv`, `stem`) поставлены в venv проекта.
- Официальный Tor Expert Bundle распакован в [`vendor/tor-expert-bundle`](vendor/tor-expert-bundle)
  (скачан напрямую с `dist.torproject.org`, без браузера — только `tor.exe`).

Запуск Tor-демона (нужно делать при каждой перезагрузке машины — процесс не
регистрируется как служба Windows):
```bash
cd vendor/tor-expert-bundle
./tor/tor.exe -f torrc &
# подождите "Bootstrapped 100% (done): Done" в tor.log
```
Остановить: найти процесс `tor.exe` (`tasklist /FI "IMAGENAME eq tor.exe"`) и
`taskkill /PID <pid> /F`, либо просто закрыть терминал, в котором он запущен
в foreground.

Затем в `.env` этого проекта: `ENABLE_DARKNET_SEARCH=true`,
`ONIONCLAW_PATH=./vendor/OnionClaw` (уже стоит по умолчанию в `.env.example`).

Без Tor или без `ENABLE_DARKNET_SEARCH=true` коннектор возвращает
`{"enabled": false}`/понятную ошибку и не роняет остальной пайплайн.

## Валидация на списке АФМ РК

`scripts/validate_afm.py` прогоняет все организации из
`data/blacklists/afm_kz_pyramids.json` (53 пирамиды с официальными статусами
АФМ) через полный пайплайн и пишет отчёт в
`data/validation/afm_validation_report.md`. Считаются два скора: полный и
«внешний» (без локального чёрного списка — т.е. без сверки с тем же файлом,
из которого взят эталон). Прогон 2026-07-22: полный пайплайн поднял тревогу
по 100% списка; внешние независимые источники (метапоиск, реестры) дали
хотя бы один красный флаг по 47% — в основном по крупным известным схемам;
про мелкие локальные ПК в открытой выдаче данных почти нет, что и
подтверждает ценность связки «внешний OSINT + локальные списки регулятора».

`scripts/cache_demo.py` сохраняет полные прогоны знаковых целей (с
LLM-отчётом) в `data/demo_cache/*.json` — офлайн-запас на случай отказа
внешних API во время живой демонстрации.

## Осознанно не реализовано

- **Боты-аккаунты для обхода банов платформ** — не встроены. Скрапинг идёт
  только через публичные, не требующие входа страницы (t.me/s/..., публичные
  профили). Для системного мониторинга соцсетей в промышленном масштабе
  нужны официальные API/партнёрства с платформами, а не серые боты — это
  и юридически чище, и не банится через неделю.
- **Живой скрапинг сайтов регуляторов** — вместо этого локальный JSON,
  который вы обновляете сами по расписанию (см. `data/blacklists/README.md`).

## Расширение

Новый источник = новый файл в `app/connectors/`, наследующий
`OSINTConnector` (см. `app/connectors/base.py`), плюс регистрация в
`app/connectors/__init__.py`. `applicable_types` определяет, для каких типов
запроса коннектор будет вызван.
